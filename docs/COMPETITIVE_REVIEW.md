# Public Competitive Review

Reviewed: 2026-08-05.

These are publicly discoverable projects associated with the Injective Global
Cup. Public discovery does not prove that every project completed the private
Typeform submission.

## CupOracle MCP

Public repo: https://github.com/edycutjong/cuporacle-mcp

What it does well:

- one sharply defined agent product,
- a short judge reproduction path,
- extensive automated tests and CI,
- published package and public documentation,
- transaction receipt links and explicit spend controls.

What Cup Signal adopted:

- a three-minute judge guide,
- an automatically generated proof bundle,
- clearer separation between protocol proof and product UI.

## LineLock

Public repo: https://github.com/edycutjong/linelock

What it does well:

- receipt-first product narrative,
- public ledger and honest placeholder labeling,
- narrow API surface with strong invariants,
- visible status and demo documentation.

What Cup Signal adopted:

- a dedicated `STATUS.md`,
- explicit claim boundaries,
- proof artifacts that can be inspected without running the UI.

## AgentDuel

Public repo: https://github.com/edycutjong/agentduel

What it does well:

- memorable two-agent narrative,
- deterministic settlement and replay framing,
- broad unit and end-to-end coverage,
- strong visual identity.

What Cup Signal retained as its own advantage:

- a wider fan-facing matchday workflow,
- richer World Cup and player exploration,
- a lower-friction non-wallet demo.

## Striker OS

Public repo: https://github.com/thesithunyein/striker-os

What it does well:

- similar match-intelligence positioning,
- concise x402/MCP/Agent Skill mapping,
- focused tests for its model and paid endpoint.

Cup Signal differentiator:

- a more complete product cockpit,
- configurable model weights,
- deeper player analytics and tournament data.

## CupPulse AI

Public repo: https://github.com/sundarAlok/cup-pulse-ai

What it does well:

- broad fan product framing,
- rewards and leaderboard concepts,
- a conventional app structure that is easy to understand.

Cup Signal differentiator:

- more inspectable Injective protocol surfaces,
- local MCP and Agent Skill workflows,
- a deterministic proof bundle.

## Decision for the remaining judging window

Cup Signal will not imitate competitors by fabricating transaction hashes or
rushing a funded wallet into the repository. The highest-value work is:

1. keep every submitted URL healthy,
2. make protocol evidence independently inspectable,
3. keep the technical boundary honest,
4. preserve the stronger fan-facing product experience,
5. avoid breaking migrations during judging.
